DATABASE SCHEMA
================================================================================

Tables Provided (5 tables)
──────────────────────────

users
├─ id (INT, PRIMARY KEY)
├─ email (VARCHAR, UNIQUE)
├─ password (VARCHAR)
├─ first_name, last_name
├─ role (student, faculty, admin)
└─ timestamps

conversations
├─ id (INT, PRIMARY KEY)
├─ conversation_id (VARCHAR, UNIQUE)
├─ user_id (INT, FOREIGN KEY)
├─ title (VARCHAR)
└─ timestamps

conversation_messages
├─ id (INT, PRIMARY KEY)
├─ conversation_id (VARCHAR, FOREIGN KEY)
├─ user_message (TEXT)
├─ bot_response (TEXT)
├─ message_type (ENUM)
└─ timestamps

newsletter_subscribers
├─ id (INT, PRIMARY KEY)
├─ email (VARCHAR, UNIQUE)
├─ name (VARCHAR)
├─ verification_token
├─ is_verified (BOOLEAN)
└─ timestamps

content
├─ id (INT, PRIMARY KEY)
├─ title, slug (VARCHAR, UNIQUE)
├─ description, content (TEXT)
├─ content_type (ENUM)
├─ tags, author_id
├─ published (BOOLEAN)
└─ timestamps
